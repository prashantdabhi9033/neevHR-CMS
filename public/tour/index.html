How it is built

Three ideas run through every screen.

01

Configuration, not customisation

Leave, attendance, payroll, expense and review policies are rule sets assigned to employee groups. Your HR admin sets them. No code change.

02

One record, every change dated

Promotions, transfers and pay changes sit on one timeline. History is never overwritten, and reports and the org chart run as of any date.

03

Analytics everywhere

Every list can become a report, every report a chart, and every chart drills down to the records behind it.

The module universe
